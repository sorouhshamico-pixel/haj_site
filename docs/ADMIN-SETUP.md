# إعداد لوحة التحكم

هذا الدليل يشرح خطوات تفعيل لوحة التحكم (`/admin`) خطوة بخطوة. اللوحة مبنية بحيث **الموقع العام يشتغل عادي تمامًا حتى لو الخطوات دي لسه ما اتعملتش** — هي إضافة منفصلة تمامًا.

## أول حاجة: هل تم الإعداد؟

لو فتحت `/admin/messages` أو `/admin` ولقيت رسالة "قاعدة البيانات غير مُعدّة بعد"، معناها الخطوات تحت لسه ما اتعملتش.

## 1. إنشاء قاعدة بيانات (Neon Postgres عبر Vercel)

1. افتح مشروعك في [vercel.com](https://vercel.com) → تبويب **Storage**.
2. اختر **Create Database** → **Neon (Postgres)** → اتبع الخطوات (فيه خطة مجانية كافية لهذا الاستخدام).
3. بعد الإنشاء، Vercel هيضيف متغير `DATABASE_URL` تلقائيًا لمشروعك — تقدر تتأكد منه في **Settings → Environment Variables**.
4. لو بتشتغل محليًا (على جهازك)، انسخ نفس القيمة وحطها في ملف `.env.local` (انسخ `.env.local.example` وسمّيه `.env.local`).

## 2. إنشاء الجداول

بعد ما تحصل على `DATABASE_URL`، شغّل محتوى الملف `src/lib/schema.sql` مرة واحدة على قاعدة البيانات. أسهل طريقة:

- من داخل لوحة Neon نفسها (Vercel → Storage → قاعدة البيانات → **Query** أو **SQL Editor**)، الصق محتوى `src/lib/schema.sql` واضغط تشغيل.

الجداول آمنة تُشغّل أكتر من مرة (`CREATE TABLE IF NOT EXISTS`).

## 3. بيانات تسجيل الدخول

في `.env.local` (وفي إعدادات Vercel للإنتاج)، أضف:

```
ADMIN_USERNAME=اسم-مستخدم-من-اختيارك
ADMIN_PASSWORD_HASH=... (شوف تحت)
SESSION_SECRET=... (شوف تحت)
```

**لتوليد `ADMIN_PASSWORD_HASH`** (لا تحط كلمة المرور نفسها أبدًا، بس الـ hash بتاعها):

```bash
npm run hash-password "كلمة-المرور-اللي-هتستخدمها"
```

انسخ الناتج وحطه كقيمة لـ `ADMIN_PASSWORD_HASH`.

**لتوليد `SESSION_SECRET`** (نص عشوائي طويل بيُستخدم لتوقيع جلسة الدخول):

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

## 4. الدخول

افتح `https://your-site.com/admin/login` وسجّل الدخول بالبيانات اللي حطيتها.

## الوضع الحالي وما هو قادم

**متوفر الآن:**
- تسجيل دخول آمن (كلمة مرور مشفّرة bcrypt، جلسة موقّعة JWT صالحة 8 ساعات، حماية كل صفحات ونقاط `/admin` عبر middleware، حد أقصى 5 محاولات دخول كل 10 دقائق).
- صندوق رسائل نموذج التواصل — الرسائل بقت بتتحفظ فعليًا وتظهر هنا (النموذج على الموقع رجع يشتغل بمعنى الكلمة، مش بس واجهة).
- إحصائيات أساسية: عدد الزيارات آخر 30 يوم، وأكثر الصفحات زيارة.

**قادم في مراحل تالية** (حسب طلبك الأصلي): تعديل محتوى الموقع (البرامج، المقالات، الأسئلة الشائعة) من اللوحة مباشرة، وإدارة معرض الصور برفع صور جديدة (سيحتاج تفعيل Vercel Blob بنفس أسلوب قاعدة البيانات).

## ملاحظات أمان

- صفحات `/admin` مستبعدة من محركات البحث (`robots.txt` + `noindex`).
- الحد الأقصى لمحاولات الدخول الفاشلة يعتمد على ذاكرة الخادم اللحظية — رادع جيد ضد المحاولات العشوائية، لكن مش بديل كامل عن حماية على مستوى الشبكة لو احتجتوا مستوى حماية أعلى مستقبلًا.
- لا تشارك `SESSION_SECRET` أو `ADMIN_PASSWORD_HASH` مع أي حد، ولا ترفعهم لأي مكان عام (ملف `.env.local` مستبعد من git تلقائيًا).
